# Загрузка, страницы и названия в GPT

Три связанные ошибки чтения:

- Статус обновления находился в начале прокручиваемой истории. После быстрого
  кешированного ответа подготовительный индикатор гас, а канонический запрос
  ещё выполнялся. Теперь зарезервированный кружок над вложениями связан также
  с загрузкой/сверкой истории; он не зависит от положения прокрутки. Подгрузка
  старых сообщений меняет подпись кнопки до завершения. При смене чата состояние
  сверяется с его собственным выполняющимся запросом.
- Hub отсчитывал 20 публичных записей вместе с commentary и незавершёнными
  ответами, которые основной чат скрывает. Общий предикат показа теперь используется
  и для границ страниц. Страница содержит 20 видимых сообщений (последняя — остаток),
  а промежуточные записи сохраняются в непрерывном каноническом диапазоне.
  Курсоры, точные переходы к источнику, prefix/delta и исходные ID сохранены.
- Токен `entity` удалялся целиком. Проверка исходного публичного ответа о книжных
  магазинах подтвердила форму `entity` + JSON `[native ID, visible name]`.
  Hub сохраняет экранированное название в исходной позиции, включая жирные
  заголовки списков. Внутренний ID не превращается в выдуманный URL; обычные
  ссылки/источники остаются ссылками. Нативные интерактивные карточки организаций
  не воспроизводятся. Неизвестные/неполные токены не раскрывают служебные данные.

Изменяется web и нормализация/пагинация Hub. Native Graph уже передаёт нужный
публичный текст, поэтому перезапуск или замена GPT runtime/Windows helpers
не требуется. Квитанции, отправки, исходная история и черновики не изменяются.

Проверка: целевые тесты entity/истории, TypeScript; Chromium/WebKit на реальном
GptWorkspace с задержанными cache/canonical/older чтениями, 20→40 сообщениями,
ошибкой чтения и сохранённым черновиком, без отправок. Проверены снимки четырёх
тем на телефоне, при уменьшенной высоте, компактном и широком планшете.
Физический iPhone отдельно не проверялся.
