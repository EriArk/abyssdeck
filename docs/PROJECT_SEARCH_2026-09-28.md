# Поиск и повседневные команды

Дополнение к ночному проходу по просьбе владельца: практический UX для двух
участников, без работы над установщиками. Связано с #221, #228 и #202/#205
из блока общения. Issue не закрывались и комментарии не публиковались.

- Панель команд ищет содержимое текущего проекта: записи, планы, сохранённые
  сообщения Codex и названия файлов/изображений Results. Режим «Все доступные»
  расширяет область. Привязка проекта включает клиент, поэтому одинаковые ID
  проектов Codex/GPT не смешиваются.
- Подробный поиск сохраняет запрос и проект из панели команд. Есть область
  «Этот чат / Этот проект / Везде» и фильтры типов. Найденный результат сохраняет
  точные result/thread/project ID и открывает карточку в исходном чате.
- Сервер читает до 500 публичных записей за страницу, отдаёт до 40 совпадений
  (20 для панели). Продолжение идёт с последней проверенной записи, включая
  страницы без совпадений. Браузер ограничен 200 совпадениями; затем уточнение.
  Смена текста/области отменяет старый запрос и очищает выдачу.
- Планы, Общение и Уведомления доступны в панели команд и настройке собственных
  сочетаний. Общение/Уведомления появляются только при включённом team workspace.
- Исправлено сжатие поисковых карточек темой, наложение строк и перегрузка окна
  пояснениями при открытой клавиатуре. Область поиска раскрывается отдельно;
  Close остаётся на месте, длинные названия переносятся.

Границы: файлы ищутся по публичному названию, без чтения бинарников/путей/payload;
папки ПК не обходятся. Полная история GPT ищется только в выбранном чате;
проектный поиск GPT содержит сохранённые записи, не сканирует его native-чаты.
Ни поиск, ни переходы не отправляют сообщения и не меняют native receipts.

Проверено: 8 серверных тестов поиска/команд (включая разреженные страницы,
совпадающие ID проектов разных клиентов, точные файлы и исключение внутренних
payload), TypeScript Hub/web, Chromium и WebKit: продолжение 55 совпадений,
отмена устаревшего запроса, фильтры, точная карточка, сохранение черновика.
Снимки четырёх тем, телефон/клавиатура/планшет/desktop; фактический просмотр
снимков выявил и устранил сжатие карточек. Физическая приёмка остаётся владельцу.

Схемы баз и контракты помощников ПК не меняются. Активация всего ночного выпуска
фиксируется в CURRENT_STATUS.md после штатного обновления с ожиданием idle.
