# Независимый браузер Companion

`codexweb_browser` предоставляет браузер WebView2 через существующий MCP/SSH
маршрут ПК. Он нужен, когда настольное приложение Codex закрыто и его собственный
`cua` / `iab` недоступен. Это отдельный инструмент, не восстановление закрытого
внутреннего хоста OpenAI. Обычный Chrome не запускается и его профиль не копируется.
Окна можно увидеть на ПК и через существующее удалённое представление ПК.

Инструменты: `open`, `tabs`, `observe`, `act`. Наблюдение возвращает текст,
элементы и снимок страницы. После действия нужно новое наблюдение; потерянный
ответ не повторяет ввод. Поддержаны обычный вход, парольные поля и формы.
Пароли не включаются в снимок DOM и не журналируются адаптером. Аргументы MCP
могут попадать в историю самого Codex. Профиль сайтов сохраняется отдельно в
`%LOCALAPPDATA%/CodexWeb/browser/profile`; это не хранилище паролей.

Сборка: `ops/windows/Build-Browser.ps1 -OutputDirectory <новая папка>`.
Нужны установленный WebView2 Runtime и WebView2 SDK (параметр `WebViewSdk`).
Установка: `ops/windows/Install-Browser.ps1 -PackageDirectory <папка>`.
Установщик проверяет хеши, сохраняет прежний task/config и регистрирует независимую
Limited/Interactive задачу `CodexWebBrowser`. Хост доступен только тому же
Windows-пользователю через локальный named pipe; TCP-listener отсутствует.
Существующий Codex broker и его активные ходы не перезапускаются.

Работающий браузер обновляется после закрытия его окон и остановки собственной
задачи; установщик не останавливает его автоматически. Старые версии сохраняются.
Этот дополнительный модуль пока не входит в подписанный автообновляемый пакет
Companion. Не считать ручную установку на ПК владельца установкой у остальных.

В проекте «Навыки, плагины и инструменты проекта» → «Переподключить инструменты»
вызывает поддержанный `config/mcpServer/reload` через существующий исполнитель.
Это не возобновление диалога и не запуск нового нативного writer. Сам список
перечитывается без переподключения при обычном открытии.

Проверка: `node tests/companion-browser.acceptance.mjs` использует установленный
MCP, одноразовую локальную форму, снимок, заполнение обычного/парольного поля и
однократную отправку. Закрывает только своё тестовое окно.
