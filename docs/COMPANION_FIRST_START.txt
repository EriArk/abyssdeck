AbyssDeck Companion 0.5.5 — Windows x64

1. Распакуйте весь архив в свою папку. Откройте Install.cmd.
   SDK и отдельный .NET устанавливать не нужно. Новый Companion откроет окно
   настройки; после установки он доступен также в меню Пуск и системном трее.
2. В Обзоре укажите HTTPS-адрес вашего Hub, свой логин и пароль Hub.
   Пароль не сохраняется. Защищённое подключение привязано к вашему Windows-профилю.
3. После входа мастер сам готовит личный пакет подключения и устанавливает
   недостающие программы. Подтверждение Windows, собственные входы Tailscale,
   Codex/GitHub и выбор папки требуют вашего действия. Текст шага виден в Обзоре.
4. Администратор подтверждает отпечаток ПК в вебе. Затем активируйте подключение
   в своём веб-профиле. Управление пользователями/Hub остаётся в вебе.

Прерванная настройка
Нажмите «Продолжить настройку»: сохраняются тот же запрос, выбранные папки и
точный отчёт. Уже работающий мастер не запускается второй раз. Если сервер
сообщил об истёкшем пакете, войдите в Hub заново для нового подключения.
Работающие задачи, аккаунты и проекты не удаляются и не запускаются повторно.

Состояние и ремонт
Галочка означает подтверждённую готовность. «Готов по запросу» — нормальное
состояние вспомогательного модуля. Дополнительные неиспользуемые компоненты
показаны отдельно. «Исправить и проверить» восстанавливает остановленный собственный
модуль; отсутствующие файлы вспомогательных модулей берутся из проверенного Hub.
Сам исполнитель Codex не переустанавливается этим действием: переход исполнителя
нуждается в отдельной проверке простоя и сохранении его конфигурации.

Локальный терминал
Доступен до подключения SSH. Вставка меняет только поле; «Отправить» — отдельное
действие. Пароль вводите отдельным маскированным полем только в реальный запрос
текущего процесса. Команды и пароли не сохраняются приложением и не повторяются
при восстановлении связи. Кнопки логина готовят команду, но не выполняют её сами.
При новом выводе экран следует только если вы уже находитесь внизу.
Закрытие терминала завершает только этот терминал. Выход из основного окна
Companion не закрывает отдельное окно терминала или запущенные компоненты.

Для уже подключённого ПК
Нынешние профиль, рабочие папки и прямое LAN-подключение сохраняются. Не создавайте
новую пару поверх существующего подключения. Обновление UI независимо от workers.

Обновления и восстановление
В Настройках включены проверка подписанных обновлений и ограниченное
автовосстановление. Обновление сначала загружается и проверяется; установка
происходит после скрытия окна и завершения настройки. Можно нажать «Установить»
вручную. Если новая версия не подтвердила запуск, возвращается прежняя.
Настройки, подключение, аккаунты и рабочие задачи сохраняются. Программы компонентов
обновляются отдельно от их рабочих данных и квитанций.
Общий счётчик «Версии пакета» показывает, сколько компонентов полностью
перешло на установленный выпуск. Версия интерфейса сама по себе не означает
завершение всех переходов. Галочка компонента подтверждает файлы пакета,
задачу Windows, конфигурацию и рабочее состояние. Обновление ждёт завершения
работы компонента. Для вспомогательных модулей доступен возврат прежней версии.
Если старая задача требует прав администратора, нажмите «Ремонт с подтверждением
Windows» и подтвердите стандартное окно Windows на ПК. Отмена оставляет прежнюю
задачу. После подтверждённого отката можно повторить ремонт вручную.
Для Codex Hub отдельно подтверждает простой и проверяет прежний аккаунт после
переключения. Активные чаты не прерываются; сообщения и команды не повторяются.
Восстанавливаются только известные собственные остановленные вспомогательные
компоненты. Выключенные, работающие и непроверенные задачи не трогаются.
После неудачных попыток включается пауза. Ручной ремонт остаётся доступен.
Обе автоматические функции можно отключить в Настройках.

Встроенный браузер
Companion содержит отдельный браузер с собственным профилем. После привязки ПК
он устанавливается из проверенного пакета и подключается к инструментам Codex.
Если WebView2 отсутствует, установщик пробует подготовить его через Windows Package
Manager. Запросы Windows завершаются лично; затем можно нажать ремонт.
В «Компонентах» проверяются файлы, подключение инструментов и ответ браузера.
Открытые вкладки сохраняются при обновлении Companion. Обновление самого браузера
ждёт окончания работы. Старая версия 1.0.0 не поддерживает переключение на ходу:
для её первого перехода потребуется закрыть работу браузера и завершить его процесс
или выйти из Windows. Новые версии переключаются автоматически при отсутствии вкладок.
