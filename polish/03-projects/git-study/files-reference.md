# Вход в общий файловый менеджер

![Вход в общий файловый менеджер](files-reference.png)

Снимок интерактивного предложения Git; тестовые данные, не работающий репозиторий.
Проверен браузером Chromium. Не является проверкой физического устройства.

Показан подписанный снимок существующего общего файлового окна. Внутренние
команды на снимке не интерактивны; при внедрении открывается существующий модуль.
