# Git — интерактивное предложение, 3 октября

Это макет для обсуждения, не установленное изменение. Данные файлов, коммитов,
релиза и результаты операций демонстрационные. Ни одна операция не обращается
к Git, GitHub, рабочим файлам или аккаунтам.

## Компоновка

- Шапка: проект и компьютер, компактный вход в Файлы, сведения о репозитории.
- Ветка и отношение к upstream видны до открытия подробностей.
- Основной экран — изменения: узкий регулируемый список, большое сравнение.
  Отметка включает файл в будущий коммит; нажатие имени открывает разницу.
- Проверка коммита рядом с выбранными файлами. Push остаётся отдельной операцией.
  Это сохраняет существующий смысл Delivery: коммит выбранного рабочего
  содержимого. Макет не объявляет полноценный stage/unstage реализованным.
- История, ветки и релизы заменяют содержимое тех же панелей. Ветки в этом
  предложении только показываются; переключение/слияние отдельно не утверждены.
- На телефоне список и детали сменяют друг друга с явным возвратом.
- Цвета и материалы зелёной, 2000, Органайзера и тёмной тем сохранены.
  Тема и ширина списка доступны в настройках макета. Все действия локальны.

## Файлы — тот же общий модуль

Владелец уточнил: файловый менеджер в Git нужен как отдельное окно и должен
быть **тем самым общим файловым менеджером**, а не его копией или новой
реализацией для Git. Это исправляет прежнее исключение Git/GitHub.

Кнопка «Файлы» в этом автономном макете показывает **неизменённый снимок**
действующего общего окна из `polish/05-files/commands-2026-10-03` в выбранной
теме. Снимок явно подписан, его внутренние кнопки не интерактивны. Так не
создаётся ещё одна демонстрационная реализация менеджера. Возврат сохраняет
выбранный файл Git и текст коммита. Изображение использует тестовый проект
`Project`, а не частные рабочие файлы. Встраивание повторяется командой
`node polish/03-projects/git-study/embed-file-references.mjs`.

При внедрении Git должен открывать существующее окно/общий файловый модуль
с точным контекстом репозитория и компьютера. Удалённый источник GitHub остаётся
удалённым источником со своими операциями и версиями; это не разрешение заменить
его локальной папкой. Родительский Git остаётся смонтированным со своим черновиком.
Результаты по-прежнему лента, общий просмотрщик не перепроектирован.

## Граница предложения

Перетаскивание окна, его размеры, док, общий просмотрщик и файл-операции уже
принадлежат общим модулям приложения. Этот макет не дублирует их поведение.
При внедрении нужны существующие admission/receipt/conflict проверки Delivery,
а не обработчики из демонстрации. Source, installed release и пользовательская
оценка дизайна учитываются отдельно.

## Проверка и снимки

Chromium и WebKit: 32 сочетания четырёх тем и ширин 1060/768/390/320px.
Проверены отсутствие горизонтального выхода, выбор и отметки файлов, два режима
diff, история/ветки/релизы, разделитель с клавиатуры, проверка коммита и отдельная
симуляция отправки, возврат из Files с тем же выбором и черновиком. Ошибок JS нет.
Это проверки только макета; приложение и физические устройства ими не проверены.
Результаты: [checks.json](checks.json).
