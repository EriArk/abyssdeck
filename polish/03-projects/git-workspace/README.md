# Git — рабочий интерфейс, 3 октября 2026

Продолжение согласованного [макета](../git-study/README.md). Это снимки production
компонентов на локальном проверочном проекте, а не HTML-демонстрация.
Реальные пользовательские репозитории во время проверок не изменяются.

- «Изменения»: узкий регулируемый список и большой diff рядом. Флажки выбирают
  рабочие файлы для существующей операции коммита; отдельно доступен просмотр индекса.
- «Файлы» открывают существующий `ProjectFiles` / `FileBrowser` с тем же project ID
  и выбранным путём. Git остаётся смонтированным. Удалённый GitHub не заменяется
  локальной папкой.
- Проверка коммита и отправка используют прежнюю «Доставку», точные отпечатки
  и долговечные квитанции. Подготовка ничего не исполняет; подтверждение отдельное.
  Потерянное подтверждение проверяется по прежнему ID. Старое завершение не стирает
  новый черновик.
- На телефоне список и diff сменяют друг друга со стрелкой возврата; на планшете
  доступны разделитель, общая геометрия окна и сворачивание в док.
- История показывает сведения о последних коммитах; diff старого локального
  коммита пока отсутствует в серверном контракте. Ветки показываются без
  переключения/слияния. Stage/unstage этот проход не добавляет.

Снимки `tablet-*` показывают четыре темы, `paired` — сравнение рядом,
`phone-list` / `phone-diff` — телефон, `commit-review` — подтверждение коммита.
Возле каждого PNG есть краткий MD. Это автоматическая браузерная проверка,
не утверждение о проверке физического iPad.

Проверки: `tests/project-git.browser.mjs`, `project-delivery.browser.mjs`,
`window-dock.browser.mjs` в Chromium/WebKit, web typecheck/build, help-content.
Генерация этих снимков: `node tests/project-git.browser.mjs` после web build.

Общий просмотрщик остаётся следующей отдельной темой обсуждения.
