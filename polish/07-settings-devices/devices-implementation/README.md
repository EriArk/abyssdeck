# Устройства: рабочая компоновка

3 октября 2026. Реализация [согласованного эскиза](../devices-study/README.md)
в существующих React-компонентах.

- Компактный выбор машины, обновление и отдельное меню её действий.
- Сводка и терминал внутри общего тематического корпуса. На широком экране сводка
  изменяет ширину и сворачивается; узкое окно использует вкладки независимо от
  размера всего экрана. Общие геометрия окна, док и разделитель сохранены.
- Название сессии, состояние подключения и её действия находятся в одном ряду.
  Завершение сессии требует подтверждения. Esc, Tab и стрелки раскрываются снизу.
- Каждая машина сохраняет выбранную вкладку и сессию в открытом окне. Черновики
  команд привязаны к точному терминалу и не пишутся в browser storage. Пароли не
  сохраняются. Переходы не отправляют ввод и не завершают процессы.
- При потере связи остаётся последняя доступная системная сводка с явным статусом.
  Фоновые чтения одного устройства не накладываются друг на друга.
- Контекстная справка описывает новые элементы управления.

## Воспроизведение

После сборки web:

```powershell
$env:DEVICES_LAYOUT_OUTPUT='polish/07-settings-devices/devices-implementation'
node tests/devices-layout.browser.mjs
node tests/devices.browser.mjs
node tests/terminal-release.browser.mjs
node --test tests/devices.test.mjs tests/terminal-release.test.mjs
```

Первый сценарий проверяет четыре темы на 1366×1024, 768×1024, 390×844, 320×700
и 390×430 в Chromium и WebKit. Также проверяются отдельные сессии/черновики,
очистка пароля, отсутствие ввода при навигации, клавиши, меню по возможностям
машины, отмена опасных действий, завершение только выбранной сессии и ширина сводки.
Существующий Devices-сценарий проверяет ввод, буфер обмена, прокрутку и док;
release-сценарий — занятые/простаивающие команды, повторное открытие, потерю
зрителя и ровно один Enter после вставленной завершающей новой строки.

Фактическая публикация и её квитанция фиксируются отдельно в
[CURRENT_STATUS](../../../docs/CURRENT_STATUS.md).
