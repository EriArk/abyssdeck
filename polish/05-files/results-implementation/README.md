# Results: рабочая реализация

Одобренный макет перенесён в общую панель Codex/GPT. Results остаётся лентой материалов.

- Файлы — строки; ссылки и HTML-демо имеют такое же боковое меню.
- Изображения — две колонки карточек с тонкой рамкой/подложкой и меню на миниатюре.
- Codex «Рассуждения» — запрос, раскрываемые публичные шаги, работа между ними.
- Плотность меняется по режиму экрана. Старые действия не теряются.

Снимки рядом с MD: четыре темы, изображения на 390 px, рассуждения на 1024 px,
отдельный пример меню файла. Это production-компоненты с контролируемыми данными,
а не очередная HTML-имитация. WebKit; фактическая установка отражена в CURRENT_STATUS.

Проверка: `node tests/results-feed.browser.mjs` — Chromium/WebKit, четыре темы,
390/1024 px. Проверены положение меню, сохранение раскрытия, точные скачивания,
ZIP, окно отправки/возврат, галерея, исходное сообщение и GPT public steps.
`tests/codex-results.test.mjs` проверяет пагинацию, изоляцию thread/project,
сохранение команд/diff/уточнений и отсутствие выдуманной хронологии для старых записей.

Сервер показывает только сохранённые публичные данные. Старый запрос появляется при
обычном чтении его native history; до этого карточка называется «Ход задачи».
Raw/private thinking не читается. Физическая проверка iPad не заявляется.

Установлено: `b3c8666`, engine + gateway, 3 октября 2026. Проверены HTTP-файлы и здоровье сервисов. Подробности и границы проверки — в [CURRENT_STATUS](../../../docs/CURRENT_STATUS.md).
