# Markdown · organizer · 1024px

Браузерная фикстура реализации; исходники: `apps/web/src/`. Не проверка физического устройства.

Правка в том же окне. Компактные команды применяются к выделению; отмена, просмотр и возврат сохраняют документ. Тестовая строка `selected text` выделена жирным.

На узком экране инструменты переходят на дополнительные ряды; содержимое прокручивается внутри окна. Заголовок и закрытие остаются доступны.
