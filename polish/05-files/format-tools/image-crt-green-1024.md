# Разметка изображения · crt-green · 1024px

Браузерная фикстура реализации; исходники: `apps/web/src/`. Не проверка физического устройства.

Просмотр/разметка в одном корпусе; инструменты маркера, пера, стрелки, рамки, подписи, обрезки, Undo/Redo и поворота. Показана копия после поворота и обрезки, 120×200 px. PNG сохраняет прозрачность; JPEG явно использует белый фон. Исходный файл не изменяется.

На узком экране инструменты переходят на дополнительные ряды; содержимое прокручивается внутри окна. Заголовок и закрытие остаются доступны.
