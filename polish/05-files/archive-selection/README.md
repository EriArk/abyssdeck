# ZIP: выбор и групповое извлечение

3 октября 2026. Реальный общий просмотрщик в браузерной фикстуре; оригинал неизменен.
Выбранное скачивается одним ZIP или извлекается в папку проекта через обычную очередь
с проверкой коллизий и восстановлением. До 32 файлов и 32 МиБ распакованных данных;
пустые папки отдельно не извлекаются. Это не редактирование исходного архива.
