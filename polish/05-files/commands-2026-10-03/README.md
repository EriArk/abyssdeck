# Файловое окно — компактные команды, 3 октября

Ориентиры владельца: [GNOME Files](https://apps.gnome.org/Nautilus/),
[Dolphin](https://apps.kde.org/dolphin/),
[Thunar](https://docs.xfce.org/xfce/thunar/the-file-manager-window).
Изучены официальные снимки GNOME и Dolphin и описание устройства Thunar.
Заимствована организация: тихая шапка, путь и поиск, расположения, список,
контекстные команды. Материалы остаются темами CodexWeb.

## Что изменилось

- Замок и предпросмотр приложения — компактные ключи в шапке.
- Загрузка, новый файл/папка и выделение — ряд пиктограмм над колонками.
  Групповые команды появляются там же, а не отнимают высоту узкого списка.
- Меню элемента открывается через «…» или правую кнопку мыши.
- Одиночные Copy/Cut используют общий механизм вставки с групповыми:
  замена точной версии, другое имя, пропуск и слияние папок.
- Убран конфликт 700px-ограничения с исходной процентной шириной просмотра:
  рост ограничен местом, необходимым соседнему списку.

## Проверка базового набора

| Возможность | Состояние |
|---|---|
| Назад/вперёд/вверх, адрес, расположения, поиск, сортировка, список/значки | Уже есть; проверены общим browser-сценарием |
| Создать файл/папку, переименовать, редактировать, удалить | Есть; используются реальные временные файлы |
| Копировать/вырезать/вставить один или несколько элементов | Исправлен отдельный одиночный путь; проверены сохранение обоих и перенос |
| Конфликты и потерянное подтверждение | Сохраняются точные версии и квитанции; групповой сценарий проверяет восстановление |
| Загрузка с заменой/другим именем/пропуском | Есть, отдельный upload-сценарий |
| Скачивание файла и ZIP выбранных элементов | Есть; ZIP пока находится в режиме группового выбора после разблокировки |
| Изменение ширины, размеры/положение окна, док | Сохраняются; док виден после сворачивания, сверху у перегородки |
| Корзина с восстановлением и Undo | Нет: удаление требует подтверждения и остаётся необратимым |
| Перетаскивание между папками, Ctrl/Cmd+C/X/V, вкладки | Не реализованы в этом проходе |

Это проверка текущего набора, не заявление о полном паритете с настольными менеджерами.
Git и структура общего просмотрщика остаются отдельными обсуждениями.
