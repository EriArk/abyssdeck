# Файлы проекта — organizer, 390x844

![Экран](organizer-390x844.png)

2 октября 2026. Настоящий интерфейс, отдельный тестовый Hub и временная рабочая папка; это не снимок с физического телефона.

Общий FileBrowser: история назад/вперёд, папка выше, адрес с сегментами и ручным вводом, поиск, сортировка, список/значки. На широком экране слева расположения, выбранный файл справа. На телефоне расположения раскрываются кнопкой; просмотр файла закрывается обратно в сохранённый список.

Файловые действия используют прежние операции и подтверждения. Оформление берётся из активной темы. GitHub и Results не превращены в файловый менеджер.
