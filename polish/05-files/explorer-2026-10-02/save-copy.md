# save-copy

![Экран](save-copy.png)

Выбор проекта и папки для копии. Настоящий FileCopySave, тестовый каталог источников. При смене проекта сбрасываются предыдущая папка и история. Сохранение делегируется обычной загрузке с проверками совпадений.

Автоматический снимок WebKit, не физическая проверка устройства.
