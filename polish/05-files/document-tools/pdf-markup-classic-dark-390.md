# pdf-markup-classic-dark-390

WebKit, 390 CSS px, тема `classic-dark`. Автоматическая браузерная фикстура; не физический iPad.

Режим разметки PDF: перо, маркер, комментарии, цвет и толщина, Undo/Redo и экспорт копии. Страница остаётся фиксированной; инструменты встроены в общий корпус.
