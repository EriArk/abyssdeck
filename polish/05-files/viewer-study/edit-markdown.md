# Инструменты Markdown

WebKit, 780 px. То же окно и источник, текстовый черновик с командами выделения:
заголовок, жирный/курсив, список/задача, ссылка, код, Undo/Redo.
Проверены пустой текст и сохранение черновика при переходе просмотра/правки.
Это пример взаимодействия, не production CodeMirror или Markdown-рендерер.
