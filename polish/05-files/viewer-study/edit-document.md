# Разметка страницы

WebKit, 780 px. Пример страницы PDF с пометкой в том же окне.
Штрихи принадлежат отдельной странице: при перелистывании на чистую страницу
не появляются, при возврате восстанавливаются. PDF-движок и экспорт здесь
не подключены; эта проверка подтверждает только взаимодействие макета.
