# Док рабочих окон — реализация

3 октября 2026. Снимки текущего приложения в изолированном браузерном окружении
WebKit, 1366 × 1000. Условный проект и тестовый черновик; личных данных нет.
Около каждого PNG находится описание MD. Исходный согласованный макет:
[window-dock-study](../window-dock-study/README.md).

Док накладывается на край чата справа от перегородки, не раздвигая колонки.
Свёрнуто окно файлов; черновик чата остаётся доступным. Кнопка стрелки убирает
рейку к краю, оставляя счётчик. Иконка восстанавливает то же окно.
Зелёная тема использует приборную рейку, «2000» — пластиковый блок,
органайзер — закладки. Classic использует сдержанную поверхность своей темы.

`keyboard.png` — управляемая проверка рассинхронизации размеров: visual viewport
460 px, временный innerHeight 18 px. Поле сообщения остаётся в рабочей области.
Нижняя пустая часть — пространство вне имитируемого viewport, а не настоящая
клавиатура. Снимок не является проверкой физического iPad.

Поведение покрыто window-dock.browser.mjs, window-geometry.browser.mjs,
devices.browser.mjs и viewport-controls.browser.mjs в Chromium/WebKit.
Статус установки — в [CURRENT_STATUS](../../../docs/CURRENT_STATUS.md).
