Возле каждого PNG есть одноимённое описание MD. Палитра корпуса на снимках красная:
в интерфейсе сохраняется существующий выбор цвета. Organizer не получает корпус
устройства. GitHub не включён в общий файловый менеджер, Results остаётся лентой.

Разделители: мышь/Pointer Events, клавиатура, сохранение ширины локально, ограничения
ширины соседней области, двойное нажатие для сброса. При переходе к узкому экрану
сохраняется прежняя последовательная навигация. Общий механизм подключён к уже
существующим панелям; сетки полей и кнопок не становятся панелями.

Проверки: `pnpm build`, `codex-questions.browser.mjs`, `file-browser.browser.mjs`,
`file-batch.browser.mjs`, `device-chassis.browser.mjs`. Chromium и WebKit; четыре
темы, телефон/планшет/широкое окно, вложенный viewer, сохранение черновика и выбора.
В визуальном тесте чтение Linux-файла заменено точными байтами fixture: снимки
не подтверждают транспорт с реального компьютера. Проверки браузерные,
не физическое тестирование iPhone. Полная текущая подборка в `.local/qa-device-chassis/`.
