# Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/EriArk/abyssdeck/security/advisories/new)
for a suspected security issue. This repository has private reporting enabled.
Do not post credentials, private conversations, account data or exploitable
details in a public issue.

Include the affected revision/component, prerequisites, expected boundary,
observed behavior and a minimal reproduction using disposable accounts/data.
Describe impact separately from assumptions. Do not test another user's server
or access their data without permission.

AbyssDeck is actively developed; there is no published LTS or fixed response-time
commitment. Report the exact installed revision because source, web, engine,
Companion and native integration versions can differ. The maintainer will discuss
verification, remediation and disclosure in the private report.

For ordinary bugs and feature requests, use [Issues](https://github.com/EriArk/abyssdeck/issues).
For design and operational boundaries, read the [security model](docs/SECURITY.md)
and [deployment guide](docs/DEPLOYMENT.md). These documents describe controls and
limits; they are not a certification or a guarantee that every installation is safe.
