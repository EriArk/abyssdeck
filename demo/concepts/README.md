# Preserved design concept

`original/abyssdeck-demo.html` is the first independent English prototype. Its
eight files are preserved byte for byte from commit `9979549` (October 7, 2026).
It remains useful for future layout ideas, and its HTML still works on its own.

This is an archive, not the current website edition. The current demo is built
from the real application in `apps/web/src`; see [../README.md](../README.md).
The archived build/check instructions refer to their original repository paths.
Use revision `9979549` in a separate checkout if reproducing that old build.
